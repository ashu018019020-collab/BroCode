# Architecture — AI Engineer Master Lab

One-directional flow: **data (`public/curriculum/*.json`) → engine (pure logic) → store (single owner) → pages (render only)**.

## Layers

| Layer | Location | Rule |
|---|---|---|
| Data | `public/curriculum/` (JSON), `public/pyodide/`, `public/sqljs/`, `public/pdf/` | Curriculum JSON generated by `tools/extract.mjs` from the source PDF; never hand-edited. The Pyodide dir also carries the three pandas dependency wheels (`python-dateutil`, `pytz`, `six`) plus `pyodide-lock.json` entries whose `sha256` digests match the shipped wheel bytes — regenerate via `.freebuff/merge-lock.cjs` if wheels change. |
| Engine | `src/engine/` — `progress` (mastery gates, section %), `mission` (daily queue), `review` (spaced repetition), `evaluate` (keyword rubrics, output checks, defense scoring), `search` (index), `keys` (persisted-key shapes + gamification policy) | Pure functions over `AppState` + curriculum. No React, no rendering. |
| Store | `src/offline/store.ts` | **Single owner** of `AppState`; only module that touches `localStorage`. Exposes `useStore()` (read), `setState()` (write), and the mutation helpers (`addXp`, `recordAttempt`, `addMistake`, `bumpStreak`, `exportProgress`, `importProgress`). |
| Runners | `src/features/coding/` — `runners` (main thread), `pythonWorker` (Pyodide in a Web Worker) | Execution only; no app state. The worker seeds `public/data`-owned datasets (`src/data/datasets.ts`) into the Pyodide FS at boot, so `pd.read_csv('<dataset>.csv')` works in every Python surface. |
| Pages | `src/pages/` | Rendering + intent; all state mutations go through store helpers. No key shapes, no level math, no gate logic inline. |

## Cross-file contracts live in `engine/keys.ts`

Every persisted-key string shape (`st:*`, `view:*`, `ia:*`, `df:*`, `resume:*`, `final:*`, `code:*`, `pg:*`, `sql:lab`) and the gamification policy (`XP_PER_LEVEL`, `levelForXp`, `levelProgress`, `LEVEL_NAMES`) is defined **only** there. Writers in pages and readers in `engine/progress.ts` must both call the same function — a typo here silently severs a mastery gate and the typecheck cannot see it. Keys are byte-compatible with existing learners' stored state.

## State ownership

- `AppState` (one object in `store.ts`): profile, xp, streak, attempts, mistakes, review, interviewAnswers, defenseAnswers, savedCode, settings, activity.
- Ephemeral UI state: local `useState` inside pages/components only.
- Curriculum: `data/curriculum.tsx` context, loaded once from JSON.

## Invariants worth preserving

- Mastery gates (`engine/progress.ts`) are the only readers of attempt semantics; pages only write.
- The app must stay fully offline: no CDN, no external fetch. Bundled runtimes: Pyodide 0.26 (Python 3.12 + numpy + pandas), sql.js (SQLite WASM), pdf.js + source PDF.
- Evaluation is deterministic (tests + keyword rubrics). No fake AI; optional online features must be labeled.
